SO-05K installation path

How to install LineageOS on SO-05K.

Confirm the model

Use this only for Sony Xperia XZ2 Compact SO-05K, codename xz2c.

Unlock the bootloader

Unlocking erases data. Follow the official Sony process for the exact handset.

Flash Lineage recovery

Enter blue-light fastboot, then flash boot, dtbo, and vbmeta to slot B.

Use fastbootd for the ROM

Flash the resized system image and vendor image to slot B.

Format data

In recovery, use Factory reset then Format data/factory reset.

Sideload Google Apps

Optional: sideload matching Android 15 arm64 Google Apps before first boot.

Important: SO-05K error 28 fix

The SO-05K has smaller system partitions than global Xperia XZ2 Compact models. A standard recovery sideload can stop at step 1/2 with error 28. This guide uses a checked resized system image flashed through fastbootd. Do not flash these images to a global XZ2 Compact, Xperia XZ3, or another Xperia.

Frequently asked questions

SO-05K LineageOS FAQ

Can SO-05K run LineageOS 22.2?

Yes. This guide covers a completed Android 15 installation for the Docomo SO-05K / xz2c.

Why does recovery show error 28?

Its smaller system partition can reject a standard sideload. Use the SO-05K fastbootd image process described above.

Will this work on Xperia XZ3?

No. Xperia XZ3 and global XZ2 Compact models use different bootloader and partition requirements.

Can I use someone else's TA backup?

No. TA backups belong to one handset and must never be shared or flashed to another phone.
