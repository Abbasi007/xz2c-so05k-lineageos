The installation path

Six steps, one specific device.

01

Confirm the phone

Only Sony Xperia XZ2 Compact SO-05K.

02

Prepare Windows

Install the driver and use a reliable USB data cable.

03

Unlock bootloader

Make a TA backup, install compatible P118 files, then unlock with xperable.

04

Flash recovery

Use blue fastboot for boot, dtbo, and vbmeta.

05

Install LineageOS

Use fastbootd for the resized system and vendor images.

06

Finish setup

Reboot, optionally install Google apps, and verify.

Read before unlocking

Unlocking and formatting erase the phone.

Charge above 60%. Confirm the model is SO-05K. Do not use a TA backup from another phone. The SO-05K has smaller system partitions than global XZ2 Compact models, so standard recovery sideload may fail with error 28.
