# Xperia XZ2 Compact SO-05K: LineageOS 22.2

This repository contains the public guide for installing LineageOS 22.2 / Android 15 on the Sony Xperia XZ2 Compact **SO-05K only**.

Read the [published guide](https://abbasi007.github.io/xz2c-so05k-lineageos/) before downloading a [release](https://github.com/Abbasi007/xz2c-so05k-lineageos/releases). Unlocking and formatting erase the phone.

## Important

- Do not use this kit on global XZ2 Compact variants or other Xperia models.
- Do not flash a TA backup from another handset.
- Verify the SHA-256 checksums before flashing any downloaded image.
